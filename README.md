# Intelligent Audit Trail Agent (Groq Edition)

An AI agent use case that handles business requests, validates user permissions against customer profiles using Groq, and automatically writes immutable verification logs into the audit registry repository.

## Installation
1. Install requirements: `pip install groq streamlit python-dotenv`
2. Add your key to a `.env` file: `GROQ_API_KEY=gsk_your_key`
3. Launch app: `streamlit run app/main.py`
